========================================================
  LC_Coop — Instalación en WINDOWS (2ª máquina)
========================================================

QUÉ ES
  Mod de cooperativo para The Last Caretaker. Cada jugador ve
  al otro (ghost). Requiere UE4SS + este mod + el sidecar.
  Para P2P no hace falta Python: el sidecar PowerShell ya viene.
  Para el servidor dedicado (server:host:puerto) y el chat SI
  necesitas Python 3 (ver "MODO SERVIDOR").

--------------------------------------------------------
PASO 1 — UE4SS
--------------------------------------------------------
  1. Descargá UE4SS: https://www.nexusmods.com/thelastcaretaker/mods/4
  2. Extraé su contenido en:
       ...\Voyage\Binaries\Win64\
     (ahí deben quedar dwmapi.dll y la carpeta ue4ss\)
  3. En   ...\ue4ss\UE4SS-settings.ini   sección [Debug],
     poné en 0:  ConsoleEnabled, GuiConsoleEnabled, GuiConsoleVisible

--------------------------------------------------------
PASO 2 — Instalar el mod (automático)
--------------------------------------------------------
  Descomprimí este paquete y, en una consola (cmd), corré:

     windows\install_lc_coop.bat "C:\...\Voyage\Binaries\Win64"

  (Si no le pasás la ruta, intenta detectarla sola.)
  Eso copia el mod y lo habilita en mods.txt / mods.json.

--------------------------------------------------------
PASO 3 — Jugar
--------------------------------------------------------
  El sidecar se lanza SOLO al entrar al juego (no hace falta terminal).
  1. Lanzá The Last Caretaker.
  2. En el juego: apretá F9, escribí la IP DEL OTRO JUGADOR
     (Tailscale 100.x.y.z o LAN), y hacé clic en "Conectar".
  3. F9 cierra el menú.
  (Si no conectara, corré a mano: sidecar\run_sidecar.bat "<carpeta Win64>")

--------------------------------------------------------
MODO SERVIDOR (server:host:puerto) - requiere Python 3
--------------------------------------------------------
El sidecar PowerShell solo sirve para P2P/relay. Para el servidor
dedicado (y para el chat) usa el sidecar Python:

  1. Instala Python 3 desde https://www.python.org/downloads/windows/
     y marca "Add Python to PATH".
  2. Cierra el juego.
  3. El mod ya arranca el sidecar solo al abrir el juego. Si Python esta en
     PATH usa Python; si no, PowerShell. Para forzar el Python a mano, en
     ...\ue4ss\Mods\LC_Coop\Scripts\config.lua pone:
         autoStartSidecar = false
  4. Abri cmd en la carpeta del juego y corre:
         run_sidecar_server.bat
     (o desde la carpeta sidecar del paquete:
         run_sidecar_server.bat "C:\...\Voyage\Binaries\Win64")
  5. Lanza el juego. En F9 escribi:
         server:TU_HOST:TU_PUERTO
     y hace clic en Conectar.

  - El sidecar Python tiene que decir:
        [LC_Coop-net] modo servidor -> TU_HOST:TU_PUERTO
        peer confirmado (ACK)
  - Si dice "Address already in use", quedo el sidecar PowerShell
    corriendo. Cerralo (powershell.exe con coop_net.ps1) y volve a
    lanzar el Python.
  - Si no conecta, proba:
        python coop_net.py --probe TU_HOST --port TU_PUERTO --probe-timeout 5
    y manda lc_net_status.txt + las ultimas lineas de lc_sidecar.log.

--------------------------------------------------------
QUÉ ESPERAR
--------------------------------------------------------
  - Cada jugador ve al otro (ghost) moverse en su mundo.
  - Puertas: probá abrir la misma puerta en los dos.
  - El inventario/contenedores está EN PAUSA (no sincroniza).

--------------------------------------------------------
PROBLEMAS COMUNES
--------------------------------------------------------
  - "no existe ue4ss\"  -> no instalaste UE4SS (Paso 1).
  - No conecta          -> ¿el sidecar está corriendo en AMBAS PCs?
                           ¿escribiste la IP de la OTRA máquina?
  - Firewall            -> permitir UDP 27015 (si no usás Tailscale).
  - ¿Apuntar a tu propia IP? = auto-test (verás un clon que te copia).
